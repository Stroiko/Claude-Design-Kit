# /components/

Shared functional components, industry-agnostic. Subfolders:

- `navigation/` — navbars, footers, sidebars
- `forms/` — contact form, newsletter signup, multi-step form
- `feedback/` — toasts, loading states, empty states
- `data/` — stats rows, pricing tables, comparison tables

These carry structure and behavior; the industry's `DIRECTION.md` palette and fonts carry the look.
