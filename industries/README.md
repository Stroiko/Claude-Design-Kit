# /industries/

One folder per industry. Each contains:

- `DIRECTION.md` — the aesthetic commitment: personality, typography, color variables, spacing rhythm, motion budget, imagery, anti-patterns, recommended section order. **Read it first and follow it exactly.**
- `sections/` — page sections (`hero-*.tsx`, `features-*.tsx`, …) pre-styled to that direction.
- `reference-page.tsx` — one complete assembled landing page showing the intended result.

Never combine files from two industry folders in one design.
